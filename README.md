# m5-step-sound-counter

M5Stack Core2 をつかった万歩計

歩くたびに設定した足音が鳴ります

## 画面操作

- 音声の切り替えは画面上での左右スワイプ
- カウント中でも変更可能

## ボタン操作

- Aボタンでカウント開始／停止
- Bボタンでログ画面表示
- Cボタン長押しでカウントリセット

## ログ画面

- トータルのカウント数
- 足音別のカウント数
- 想定移動距離
- などを表示

## データ保存

- データは電源をON／OFFしても消えないこと
- カウントリセットで完全消去

## 足音

- どこかのフォルダにファイルを配備し、それを再生
- 音声ファイル形式はmp3, wavを想定
