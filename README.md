# m5-step-sound-counter

M5Stack Core2 をつかった万歩計

歩くたびに設定した足音が鳴ります

この万歩計は人間の腰あたりにつける想定です。

## 画面操作

- デフォルトは無音でカウントだけ（画面にはステップカウンターのタイトル）を表示
- 音声の切り替えは画面上での左右スワイプ
- 画面はfilesの中にある画像ファイルを表示させる
- カウント中でも変更可能
- カウントした数字（総合計）は画面上に表示

## ボタン操作

- Aボタンでカウント開始／停止
- Bボタンでログ画面表示
- Cボタン長押しでカウントリセット

## ログ＆設定画面

- トータルのカウント数
- 想定移動距離（km / m）および消費カロリー（kcal）
- 足音別の歩数内訳バーグラフ
- **音量調整スライダー**: タッチスライドまたは `[-]` `[+]` タップで 0%〜100% 調整可能（NVSで保存）

## データ保存

- 歩数、選択キャラクター、音量設定は電源をON／OFFしても保持（NVS）
- Cボタン長押し（約1.5秒）で完全消去（リセット）

## テーマ・足音・画像のカスタマイズ (`data/themes.json`)

キャラクターや足音、画像は `data/themes.json`（SPIFFS）で管理されており、JSONを書き換えるだけで簡単に追加・変更・並び替えが可能です（ファームウェアの再コンパイル不要）。

```json
[
  {
    "id": "Default",
    "name": "STEP COUNTER",
    "image": "",
    "wav": "",
    "color": "0x07FF"
  },
  {
    "id": "Broly",
    "name": "Broly",
    "image": "/image/Broly.png",
    "wav": "/wav/Broly.wav",
    "color": "0x34E1"
  }
]
```

- `id`: 一意の識別子
- `name`: 画面ヘッダーに表示する名前
- `image`: 画像パス（空文字で幾何学タイトル画面）
- `wav`: 足音WAVパス（空文字で無音）
- `color`: テーマカラー（`"0x07FF"` 形式または `"#RRGGBB"` 形式）

### 音声とアセットの最適化
- 音声は `files/wav/`（または `files/mp3/`）に配置後、`python convert_audio.py` を実行すると自動的に音圧ノーマライズ＆小型スピーカー最適化（不要な超低域カット＋中音域ブースト）され、即時発音用の `data/wav/` へ配置・変換されます。
- 実機アセット転送: `pio run -t uploadfs`
